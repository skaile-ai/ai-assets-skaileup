# _concept/07_screens/<feature_slug>/

The screens one feature needs, named for the feature's slug (the same slug as `05_features/<featureset>/<feature_slug>.md` and `08_dossiers/<feature_slug>/`). Each file is one screen, described in `tree/07_screens/[feature_slug]/[screen].md`. The directory belongs to `spec-feature`; the walkthrough groups its generated navigation by this directory name.

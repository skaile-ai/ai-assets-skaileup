# _concept/04_journeys/

Who the users are and the staged map of what they are trying to do. `spec-featuresets` derives the feature roster from it rather than inventing one, so a journey missing here is a feature nobody thinks to build. The folder holds one artifact, `stories.yaml` (`tree/04_journeys/stories.md`), written by `experience-journeys`; it maps journeys and stops — no feature specs, no screens.

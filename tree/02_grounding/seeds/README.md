# _concept/02_grounding/seeds/

Material the user dropped in — pitch decks, PDFs, exports, style guides, code excerpts. Nothing
generates it and no skill edits it: a seed keeps the name it arrived with, because every skill
that quotes it cites that name. `concept-onboard` inventories each file in
`answers.json` (`tree/02_grounding/onboarding/answers.md`), grading how far it already seeds an
artifact; later skills adopt a `complete` seed and skip collecting that ground.

# _concept/02_grounding/research/step/

Research dispatched alongside one particular skill goes to `step/<skill-name>/` instead of the
topic files in `tree/02_grounding/research/README.md`. The folder name is the skill's `name:`
character for character, which is how that skill finds its research again.

## Writing it

1. Name the directory for the dispatching skill exactly.
2. Put only text findings there; its screenshots and page saves still go to
   `tree/02_grounding/findings/README.md`, with that skill's name as `step`.

## Checks

Every folder name under `step/` equals an installed skill's `name:`.

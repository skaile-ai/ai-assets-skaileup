# _concept/02_grounding/

Everything the project knew or found before any artifact was designed: what the user answered,
what research and reverse-engineering turned up, the conventions of an existing codebase, and
the material the user dropped in. Every skill may read it at any point; a skill that designs
against it cites the file it used, so a claim here is only as good as its source line.

Nothing in this folder is designed. A decision made from this evidence belongs in the numbered
artifact that owns it.

## Contents

- `onboarding/` — the one answer record and the questions routed to people outside the room.
- `research/` — topic findings written by `concept-research`.
- `seeds/` — material the user dropped in; nothing generates it.
- `standards/` — conventions discovered in an existing codebase.
- `findings/` — graded evidence and raw material, with its catalogue.

# _concept/02_grounding/onboarding/

The preferences, constraints and material a project arrives with, recorded before any artifact
is designed against them. `answers.json` holds every answer; `questions.md` holds the questions
only someone outside the room can answer. Nothing here is a decision: a technology named here
is a preference a later skill weighs.

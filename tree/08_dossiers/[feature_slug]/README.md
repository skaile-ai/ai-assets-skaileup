# _concept/08_dossiers/<feature_slug>/

The dossier of one feature, named for its slug (the slug of `05_features/<featureset>/<feature_slug>.md`). It holds one file, `index.md`, described in `tree/08_dossiers/[feature_slug]/index.md`; the lifecycle rules are in `tree/08_dossiers/README.md § Freeze lifecycle`.

# _concept/05_features/<featureset>/

One featureset: a group of features a user reaches for a single purpose. Its directory name is a lowercase, hyphenated slug with no numeric prefix, fixed in the roster by the first `spec-feature` run that opens the featureset — renaming it later rewrites every cross-reference to it. The directory holds one `<feature>.md` per feature, each described in `tree/05_features/[featureset]/[feature].md`.

## Contents

- `<feature>.md` — one feature spec, written by `spec-feature`.
